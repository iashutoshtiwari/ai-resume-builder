# Bundled LaTeX compatibility files

These files are a minimal offline fallback for the canonical `main.tex` fixture. They were sourced from their TeX Live/CTAN distributions and retain their upstream copyright and license notices:

- XCharter and its Type 1 font support files: CTAN `xcharter` distribution.
- `enumitem` and `titlesec`: upstream MIT-licensed distributions.
- `xkeyval`: LaTeX Project Public License distribution.

The runtime otherwise resolves TeX Live 2025 packages on demand and caches them in the browser. Do not remove upstream notices when updating these files.
